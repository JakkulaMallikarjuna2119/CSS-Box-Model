CSS Color Properties Demonstration

This page showcases different CSS color formats, transparency effects, background colors, and border styles.

1. Color Names Property

This heading uses a standard color name ('red'), and this paragraph uses another standard color name ('green').

2. HEX Colors Property

This section uses HEX code values for colors. The heading is colored with #FF0000 and the paragraph uses #27ae60.

3. RGB Colors Property

This section uses RGB values. The section background and border are defined using rgb() functions as well.

4. RGBA Colors (Transparency)

This section experiments with the alpha channel (transparency) using rgba() for both the background color and the border to create a layered effect.

5. HSL Colors Property

This section uses Hue, Saturation, and Lightness (hsl()) to style the headings, text, borders, and background.

6. HSLA Colors (Transparency)

This final section utilizes hsla(), combining HSL values with an alpha transparency value to style background shading and dashed borders.
