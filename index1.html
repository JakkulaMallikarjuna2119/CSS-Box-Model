CSS Box Model & Box-Sizing Task

Task Overview: This webpage demonstrates the CSS Box Model components (Content, Padding, Border, and Margin) across 3 distinct boxes, highlighting the difference between content-box and border-box.

Box 1: content-box

This box uses box-sizing: content-box. Its total width will be 300px (content) + 40px (left/right padding) + 10px (left/right borders) = 350px total width.

Box 2: border-box

This box uses box-sizing: border-box. Its total width remains strictly 300px because padding and borders are drawn inside the specified width.

Box 3: Custom Styling

This box demonstrates unique padding, a dotted border style, a green background, and a larger outer margin.

Key Takeaways from the Output:

  • Content: The actual text or inner elements inside each box.
  • Padding: Creates space inside the box between the content and the border (each box uses unique padding values).
  • Border: Outlines the box with different styles (solid, dashed, dotted), widths, and colors.
  • Margin: Controls the spacing outside the boxes, keeping them separated from one another by different gaps (15px, 30px, and 50px).
  • Box-Sizing Difference: With content-box, padding and borders expand the element's overall layout size. With border-box, the element respects the exact width you set.
